# Tiremm Navigatore Android

- Package: `it.tiremminnanz.navigatore`
- Native Android app; no WebView and no Telegram dependency.
- GPS runs in a foreground location service during active navigation.
- The app talks only to the VPN-only navigator gateway on port 19126.
- Gateway surface: destinations, navigator start/update/status/stop, APK download.
- Tiremm Innanz is the only built-in destination; all other favorites come from persistent user data.
- Backend routing and realtime deduction remain in the ATM router/API.
- Current APK version: 0.1.0 (versionCode 1).
